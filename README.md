# ITBDA4-14 Big Data Analytics Project

All code is in R and runs in Google Colab (R runtime): `notebooks/ITBDA4_14_Project_david_chaka.ipynb`.
Full write-up with inputs and outputs: `docs/ITBDA4-14_Project_Documentation.pdf`.

1. MapReduce keyword search (R mapper/reducer, Hadoop Streaming)
2. LDA topic modelling of news articles
3. WebText API: fair-use scraping and text summarisation
4. ETL: web scraping → cleaning → PostgreSQL → SQL analysis

How to run: open the notebook in Colab, set Runtime → R, upload the two zips from `data/raw/`, then Runtime → Run all.
